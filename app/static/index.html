Connect Strava

Strava sync lets AthleteOS match your activities to planned sessions and generate reflections.

You need a free Strava API app:

  1. Go to strava.com/settings/api
  2. Create an app — any name, Website: http://localhost
  3. Set Authorization Callback Domain to your Railway domain (or localhost for local dev)
  4. Copy your Client ID and Client Secret below
